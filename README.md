# Tennis Club Membership System

A full-stack web application for managing a tennis club's memberships, court reservations, and payments, designed for a club of up to 1,000 members. The requirements were written to the IEEE 830 standard to meet the client's expectations.

## Features

- **Memberships:** member accounts and membership management
- **Reservations:** court reservations
- **Payments:** payment handling for memberships and reservations
- **Admin backend:** account management, system configuration, and data management

## Tech Stack

Python, Django, MySQL. A GitHub Actions workflow is included in `.github/workflows`.
